# GS-JAVA
##  PROJETO Eco-Watch Spatial System 🌍

O Eco-Watch Spatial System é uma solução de software desenvolvida em Java baseada nos pilares do Planejamento Orientado a Objetos (POO) e Domain Driven Design. O sistema conecta diretamente os recursos de monitoramento da exploração espacial com problemas críticos de preservação ambiental na Terra. Através da simulação de uma rede de satélites artificiais (térmicos e de radar), a aplicação analisa em tempo real dados coletados de biomas terrestres vulneráveis, como a Amazônia Legal. O foco central é processar grandes volumes de dados de telemetria e assinaturas térmicas para prever catástrofes climáticas, otimizar respostas governamentais e centralizar o controle de ativos aeroespaciais voltados ao bem-estar do planeta.

A preservação dos biomas terrestres enfrenta severos desafios devido ao crescimento acelerado do desmatamento ilegal e dos focos de incêndio florestal. Métodos tradicionais de fiscalização em solo mostram-se ineficientes devido à escala monumental e ao difícil acesso às áreas de preservação na Terra. Nesse cenário, o monitoramento aeroespacial via satélite surge como a única alternativa viável para fornecer dados abrangentes e georreferenciados de forma ágil. O objetivo principal deste projeto é conceber uma arquitetura orientada a objetos capaz de gerenciar frotas de satélites e processar indicadores de degradação ambiental. Através de algoritmos de tomada de decisão, o software analisa flutuações de temperatura e alterações na cobertura vegetal. Os dados processados geram alertas automáticos de níveis críticos de emergência ambiental de forma imediata. O sistema também visa garantir a resiliência dos próprios instrumentos espaciais por meio de funções de calibragem de órbita e segurança contra tempestades solares. Dessa forma, a aplicação transforma o conhecimento científico espacial em uma ferramenta prática, inovadora e escalável. O Eco-Watch estabelece uma ponte tecnológica essencial entre a infraestrutura de satélites e a proteção ativa do ecossistema terrestre.
